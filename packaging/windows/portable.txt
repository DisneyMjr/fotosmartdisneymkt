FotoSmart portable mode

While this file sits next to fotosmart.exe, FotoSmart keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the FotoSmartData folder beside it, and writes
nothing to %APPDATA%. Copy the whole folder to move FotoSmart with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Photocraft) instead.
If FotoSmartData can't be written (for example on a read-only drive), FotoSmart says so and
uses %APPDATA%\Photocraft instead.
